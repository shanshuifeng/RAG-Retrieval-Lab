## 六、⚠️ 常见拖延陷阱

| 陷阱 | 表现 | 破解 |
|---|---|---|
| **① 追求完美环境** | 花一周调 CUDA | ⭐ **先 CPU 跑通** |
| **② 追求大数据** | 一上来就全量 890 万 | ⭐ **1 万 → 10 万 → 100 万** |
| **③ 指标没验证就往下做** | 结果很奇怪但不查 | ⭐ **M2.3 是硬门槛** |
| **④ 同时改多个变量** | "我优化了一下" | ⭐ **一次一个变量** |
| **⑤ 只跑不记录** | 两周后忘了怎么跑的 | ⭐ **每次实验必记录** |
| **⑥ 想一次写完报告** | 最后几天手忙脚乱 | ⭐ **每个里程碑写小结** |
