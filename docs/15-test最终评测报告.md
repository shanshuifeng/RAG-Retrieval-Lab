## 四、⭐⭐⭐ test 相对 dev 的三个关键检验

### 检验 ①：稠密 ≫ BM25 —— **复现，且差距更大**

| | dev | test | 变化 |
|---|---|---|---|
| D2 vs BM25 | +53.4%（d=0.822） | **+55.1%（d=1.035）** | 差距**变大**，效应量从"中"到"大" |

> ✅ **E1 的核心结论在 test 上稳健复现，且更强。**

### 检验 ②：混合检索是负优化 —— **复现**

| | dev | test |
|---|---|---|
| RRF vs 纯 D2 | 0.7085 < 0.8139（-13.0%） | 0.7681 < 0.8809（-12.8%） |

> ✅ **E2 的负面结果在 test 上几乎原样复现**——"两方法质量悬殊时混合是负优化"
> 不是 dev 的偶然，是可复现的规律。

### 检验 ③：重排有效 —— ⚠️ **没有复现**

| | dev | test |
|---|---|---|
| 重排 vs 第一段 | +2.67%（p=4.0e-28，d=0.119）**显著** | **+0.16%（p=0.625，d=0.011）不显著** |

```
dev 上：重排显著有效（+2.67%，p=4e-28）
test 上：重排几乎无效（+0.16%，p=0.625，不显著）
        ↓
⭐ 这就是 dev/test 纪律存在的意义：
   在 dev 上反复观察到的"小提升"，可能只是 dev 集的特性，
   只有 test 能给出最终裁决。
```

**可能的原因（诚实列出，不替结论拔高）**：

| 候选解释 | 依据 |
|---|---|
| test 第一段已接近天花板 | test 上 D2 本身更强（0.8809 vs dev 0.8139），重排可改空间更小 |
| query 难度分布不同 | test 每 query 平均 4.92 个正例（dev 2.60），任务性质不同 |
| dev 的小效应量本就脆弱 | d=0.119 属"可忽略"级，跨集不复现不意外 |
| 重排对 @1 还略有害 | test nDCG@1：重排 0.9015 < 第一段 0.9090 |

> ⭐ **最终结论形态**：
> - "重排**能**提升"——**不成立**（test 上不显著）
> - "重排**在这个设置下**没有带来可复现的收益"——**成立**
> - 注意这不是"重排无用"的普遍结论：第一段较弱或候选噪声更大时，
>   重排仍可能有效；本结论只对"强第一段 + K=20 + 本数据集"成立。

### ⭐⭐ 2026-10-25 审查补充：上述「候选解释」第一条已被实测证实

审查时补做了**同一 cross-encoder 接在三档第一段后**的对照（dev，1,500 query）：

| 第一段 | 基线 | 重排后 | 提升 | 相对 | Cohen's d |
|---|---|---|---|---|---|
| BM25(调优) | 0.5707 | 0.7017 | **+0.1309** | **+22.94%** | **0.558** |
| D1/small | 0.7474 | 0.8288 | **+0.0814** | **+10.88%** | **0.409** |
| D2/base | 0.8154 | 0.8542 | +0.0388 | +4.76% | 0.215 |

```
⭐⭐ 证实：第一段越弱，重排提升越大（单调关系）
   BM25 +22.94%  >>  D2 +4.76%

⭐ 因此本报告「重排在 test 上不显著」的正确定性表述是：
   「重排在【第一段已达 nDCG@10=0.88】的条件下没有提升空间」
   ❌ 而不是「重排未复现 / 重排不可靠」

   实测表明重排本身非常有效（弱第一段下 +22.94%，d=0.558 中效应），
   只是在 0.88 的第一段后面，剩余空间（11.9%）不足以体现。
```

> ⚠️ 这处修正很重要：原表述会让读者错误地低估重排的价值。
> 详见 [docs/18-项目审查报告](18-项目审查报告.md) S1。
