## 六、⚠️ 配置过程中的两个真实发现

### 发现 1：pip 配置曾被写到用户级

```
⚠️ 执行 pip config set 时，默认写到了：
   %APPDATA%\pip\pip.ini  ← 影响【所有】pip 命令

⭐ 已处理：
   · 备份原文件为 pip.ini.bak-20261017
   · 移除用户级配置
   · 改为写入 .venv\pip.ini（仅本 venv 生效）
```

### 发现 2：一个测试用例本身写错了

```
⚠️ 初版验证脚本里：
   ndcg_at_k([3,2,1], {1,2,3}, 3) 期望 < 1.0，实际 = 1.0 → 报 FAIL

⭐ 分析：
   相关集是 {1,2,3}，而 [3,2,1] 三个【全部命中】
   在二值相关性下，全命中时 nDCG = 1.0（与顺序无关）

⭐ 结论：环境没问题，是测试用例设计不当
   → 已改用"部分相关"的场景来测试排序影响
   → 这恰好印证了 docs/05 评测协议里的提醒：
     "指标实现必须仔细验证"
```
