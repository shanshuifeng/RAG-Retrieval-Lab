## 二、虚拟环境激活方式

方式 1（推荐）：直接指定解释器。

```powershell
.venv\Scripts\python.exe scripts\verify_venv.py
```

方式 2：激活后使用。

```powershell
.venv\Scripts\Activate.ps1
python scripts\verify_venv.py
deactivate
```

PowerShell 若报"禁止运行脚本"，可执行 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`（仅对当前窗口生效）。

方式 3：cmd。

```cmd
.venv\Scripts\activate.bat
```

## 六、配置过程中的两个发现

其一，pip 配置曾被写到用户级（`%APPDATA%\pip\pip.ini`，影响所有 pip 命令），已备份并改为写入 `.venv\pip.ini`（仅本 venv 生效）。

其二，一个测试用例本身写错：初版验证脚本里 `ndcg_at_k([3,2,1], {1,2,3}, 3)` 期望 <1.0，实际全命中时二值相关性下 nDCG=1.0（与顺序无关），报 FAIL。环境没问题，是测试用例设计不当，已改用"部分相关"场景测试排序影响。
