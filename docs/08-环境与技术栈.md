## 四、⭐ 安装策略（分阶段，降低风险）

### 阶段 1：纯 CPU 最小可用集（先跑通流程）

```bash
pip install PyYAML tqdm requests jieba rank_bm25
```

**⭐ 目的**：**先用 BM25 跑通 E1 基线，验证评测代码正确**——
这样即使后续 GPU 环境出问题，也已经有了可用产出。

### 阶段 2：加装向量检索

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install transformers sentence-transformers faiss-cpu
```

> ⚠️ **Windows + FAISS 的常见问题**：
> ```
> 若 faiss-cpu 安装失败：
>   备选 1：conda install -c conda-forge faiss-cpu
>   备选 2：用 hnswlib 替代
>   备选 3：⭐ 小规模时用纯 numpy 暴力检索
>          （10 万段落 × 512 维，单次检索约 50ms，可接受）
> ```

### 阶段 3：GPU 加速（如 CUDA 可用）

```bash
pip uninstall torch
pip install torch --index-url https://download.pytorch.org/whl/cu121
```

**⚠️ 风险**：CUDA 版本必须与驱动匹配（本机驱动 616.92）。
**⭐ 建议**：先确认 CUDA 可用再装，否则保持 CPU 版（慢但稳）。

## 七、⚠️ 已知环境陷阱

| # | 陷阱 | 症状 | 应对 |
|---|---|---|---|
| **1** | ⚠️ **Windows 控制台 GBK 编码** | 打印中文/emoji 报 `UnicodeEncodeError` | ⭐ 设 `PYTHONIOENCODING=utf-8`；或写文件而非打印 |
| **2** | ⚠️ **PowerShell 引号转义** | `python -c "..."` 命令被截断 | ⭐ **写成 .py 文件再执行**，不要用 `-c` |
| **3** | ⚠️ **faiss 在 Windows 装不上** | `pip install faiss-cpu` 失败 | 见上方备选方案 |
| **4** | ⚠️ **CUDA 版本不匹配** | `torch.cuda.is_available()` 返回 False | 装 CPU 版，或匹配驱动版本 |
| **5** | **HF 下载超时** | 卡在下载 | 用 `HF_ENDPOINT` 镜像或 ModelScope |
| **6** | **jieba 首次加载慢** | 第一次分词很慢 | 正常，会缓存 |
