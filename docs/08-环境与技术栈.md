## 三、安装策略（分阶段，降低风险）

### 阶段 1：纯 CPU 最小可用集

```bash
pip install requests tqdm PyYAML jieba rank-bm25
```

目的：先用 BM25 跑通 E1 基线，验证评测代码正确，这样即使后续 GPU 环境出问题，也已有可用产出。

### 阶段 2：加装向量检索

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install transformers sentence-transformers faiss-cpu datasets
```

Windows 下若 faiss-cpu 安装失败，备选方案：conda 安装 `faiss-cpu`，或改用 hnswlib，或小规模时用纯 numpy 暴力检索（10 万段落 × 512 维，单次检索约 50ms，可接受）。

### 阶段 3：GPU 加速（如 CUDA 可用）

```bash
pip uninstall torch
pip install torch --index-url https://download.pytorch.org/whl/cu121
```

CUDA 版本必须与驱动匹配。建议先确认 CUDA 可用再装，否则保持 CPU 版（慢但稳）。

## 六、已知环境陷阱

| # | 陷阱 | 症状 | 应对 |
|---|---|---|---|
| 1 | Windows 控制台 GBK 编码 | 打印中文报 UnicodeEncodeError | 设 PYTHONIOENCODING=utf-8，或写文件而非打印 |
| 2 | PowerShell 引号转义 | `python -c "..."` 命令被截断 | 写成 .py 文件再执行 |
| 3 | faiss 在 Windows 装不上 | pip install faiss-cpu 失败 | 见上文备选方案 |
| 4 | CUDA 版本不匹配 | torch.cuda.is_available() 返回 False | 装 CPU 版，或匹配驱动版本 |
| 5 | HF 下载超时 | 卡在下载 | 用 HF_ENDPOINT 镜像或 ModelScope |
| 6 | jieba 首次加载慢 | 第一次分词很慢 | 正常，会缓存 |

## 七、可复现性要求

每次实验必须记录环境并存入 results：

```json
{
  "environment": {
    "os": "Windows",
    "python": "3.12.14",
    "torch": "x.x.x",
    "cuda_available": true,
    "gpu": "RTX 4060 Laptop 8GB"
  }
}
```

不记录环境的结果等于没有结果，因为无法判断差异来自代码还是环境。
