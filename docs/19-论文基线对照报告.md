## 一、⭐⭐ 最重要的发现：项目的主指标与论文不同

```
论文用的指标：MRR@10（主）、Recall@1、Recall@50
本项目用的指标：nDCG@10（主）、Recall@10、MRR@10

⚠️ 论文【没有使用 nDCG@10】
```

这意味着：**本项目此前无法与论文对照，不只是因为语料不同，还因为指标不同**。
本报告为此专门把本项目的 test run 重算成论文口径，才建立起可比的桥梁。

---

## 二、⭐⭐ 核心不可比因素：语料规模差 81 倍

| 项 | 论文 | 本项目 | 差异 |
|---|---|---|---|
| **语料库** | **8,096,668 段**（全量） | **100,001 段**（C-MTEB 采样版） | **81×** |
| query 数（test） | 4,000 | 2,000 | 2× |
| 每 query 平均相关 | 4.90 | 4.92 | 基本一致 ✅ |
| 主指标 | MRR@10 | nDCG@10 | 不同 |

> ⭐ **语料规模是最根本的不可比因素**：在 10 万段里检索，比在 890 万段里容易得多。
> 这个差异会让本项目的所有绝对指标系统性偏高，**这是预期，不是实现有问题**。

## 三、并列对照

### 3.1 第一段检索

**论文（890 万段语料，test 4,000 query）**

| 方法 | MRR@10 | Recall@1 | Recall@50 |
|---|---|---|---|
| BM25 | **21.03** | 12.08 | 70.00 |
| DE w/ BM25 Neg | **53.96** | 41.53 | 91.33 |

**本项目（10 万段语料，test 2,000 query，已换算为百分数）**

| 方法 | MRR@10 | Recall@1 | Recall@50 |
|---|---|---|---|
| BM25（调优） | **72.46** | 17.08 | 70.25 |
| D1 / BGE-small | **87.43** | 22.56 | 92.25 |
| D2 / BGE-base | **93.72** | 26.23 | 96.57 |

### 3.2 重排

**论文（第一段 top-50 → CE）**

| 方法 | MRR@10 | Recall@1 | Recall@50 |
|---|---|---|---|
| BM25 top-50 → CE w/ BM25 Neg | 56.80 | 48.83 | 70.00 |
| DE top-50 → CE w/ DE Neg | 74.21 | 66.03 | 91.33 |

**本项目（第一段 top-20 → bge-reranker-base，K=20 是 dev 锁定的甜点）**

| 方法 | MRR@10 | Recall@1 |
|---|---|---|
| D2 + 重排（K=20） | 93.33 | 26.04 |

> ⚠️ 本项目用 K=20，论文用 top-50，重排深度不同，结果不可直接比。

## 四、⭐ 可以比什么、不能比什么

### ❌ 不能比：绝对数值

| 对比 | 本项目 | 论文 | 说明 |
|---|---|---|---|
| BM25 MRR@10 | 72.46 | 21.03 | 高 51.43 点 |
| D2 MRR@10 | 93.72 | 53.96 | 高 39.76 点 |

**原因**：10 万段 vs 890 万段。**不能据此说"我的实现更好"或"论文模型更差"。**

### ⚠️ 半可比：稠密/BM25 的相对倍数（但差异明显）

| | 稠密 / BM25 的 MRR@10 倍数 |
|---|---|
| 本项目 | **1.29×**（93.72 / 72.46） |
| 论文 | **2.57×**（53.96 / 21.03） |

```
⚠️ 两者【差距明显】，不能说"一致"。
   但这个差异有明确的解释，而且方向很有意思：

   · 小语料（10 万段）：BM25 的 MRR@10 已达 72.46（很高）
     → 稠密只剩 27% 的提升空间 → 倍数被压缩到 1.29×
   · 大语料（890 万段）：BM25 只有 21.03
     → 稠密的语义匹配优势得以充分展开 → 倍数 2.57×

   ⭐ 结论：稠密的优势随语料规模变大而【扩大】
   ⭐ 推论：本项目在 10 万段上的结论，是稠密优势的【保守下界】
```

### ⭐⭐ 完全可比：重排收益随第一段强度的变化趋势（**关键外部验证**）

**这是本报告最有价值的发现。**

| 第一段 | 重排前 MRR@10 | 重排后 | 提升倍数（论文） |
|---|---|---|---|
| BM25（弱） | 21.03 | 56.80 | **2.70×** |
| DE（强） | 53.96 | 74.21 | **1.38×** |

```
⭐⭐ 论文的数据独立显示：第一段越弱，重排提升越大（2.70× vs 1.38×）

⭐⭐ 这与本项目审查时补做的对照实验【完全同向】：

   | 第一段 | 本项目 nDCG@10 提升 | 论文 MRR@10 提升倍数 |
   |---|---|---|
   | BM25（弱） | +36.25%（K=100） | 2.70× |
   | D1（中） | +12.20% | — |
   | D2（强） | +4.76% | 1.38×（论文的 DE 相当于强段） |

   ⭐ 两个独立数据源、两个不同指标（nDCG@10 vs MRR@10）、
      两种不同语料规模（10 万 vs 890 万），都得出【同一个结论】
        ↓
   ⭐⭐ 这是"天花板效应"这一发现获得【外部独立验证】的强证据
       它不再是本项目的一次孤立的观察，而是有文献支撑的规律
```

## 五、⚠️ 一个容易误读的指标：Recall@1 为何远低于 MRR@10

本项目 BM25 的 `Recall@1 = 17.08%` 而 `MRR@10 = 72.46%`，看似矛盾。**这不是 bug**：

```
Recall@1 的定义：|Top-1 ∩ Relevant| / |Relevant|
        ↓
分母是【该 query 的全部相关段落数】（本项目平均 4.92 个）
        ↓
即使 Top-1 完全命中，也只贡献 1/4.92 ≈ 20%
        ↓
⭐ 所以 Recall@1 天然远低于 MRR@10 —— 两者分母不同

用 top-1 命中率反推（更有意义的读法）：
   本项目 BM25: Recall@1=17.08% × 4.92 ≈ 84% 的 query top-1 命中
   论文   BM25: Recall@1=12.08% × 4.90 ≈ 59% 的 query top-1 命中
        ↓
   ⭐ 84% vs 59% —— 10 万段比 890 万段容易，完全符合预期
```

> ⚠️ 本项目此前的报告里没有单独讨论过 Recall@1 的这个口径问题，
> 读者容易误以为"Recall@1 只有 17% 说明检索很差"。**必须解释清楚。**

## 六、⭐ 对本项目结论的影响

| 结论 | 论文是否支持 | 说明 |
|---|---|---|
| 稠密 ≫ BM25 | ✅ **支持** | 论文 DE(53.96) vs BM25(21.03)，方向一致；本项目差距被语料规模压缩 |
| 混合检索负优化 | ⚠️ **无法验证** | 论文未做 RRF 混合实验 |
| **重排收益随第一段强度递减** | ✅✅ **强支持** | 论文 BM25→CE 2.70× vs DE→CE 1.38×，与本项目 +36.25%/+4.76% 同向 |
| 分块劣于不切分 | ⚠️ **无法验证** | 论文未做分块消融 |

## 七、⚠️ 本对照的局限

| 限制 | 影响 |
|---|---|
| **语料规模差 81 倍** | 绝对数值不可比，只能比趋势与倍数 |
| **指标不同**（论文 MRR@10，本项目 nDCG@10） | 本项目已重算 MRR@10 建立桥梁，但 nDCG@10 的结论仍无对照 |
| **重排深度不同**（论文 top-50，本项目 K=20） | 重排结果不可直接比 |
| **论文模型是 ERNIE/RocketQA 训练版** | 本项目用现成 BGE，未微调，不是同一水平的方法 |
| **论文 test 4,000 query，本项目 2,000** | 统计效力不同 |
| 论文数字来自 ar5iv HTML 版 | 已核对 Table 4/5 原文；未拿到 PDF 原件交叉验证 |

## 九、⭐ 结论一句话

> **绝对数值不可比（语料差 81 倍），但两个关键结论获得了外部支持**：
> ① 稠密远优于 BM25（方向一致，且本项目是其保守下界）；
> ② ⭐ **重排收益随第一段强度递减**——论文 2.70× vs 1.38×，
> 本项目 +36.25% vs +4.76%，**两个独立数据源同向**。
> 这使"天花板效应"从本项目的一次观察，升级为**有文献支撑的规律**。
