> **文档版本**：v1.0 ｜ **创建日期**：2026-10-16

## 一、⚠️ 必须声明的根本局限

### 局限 1：数据集局限

| # | 局限 | 影响 |
|---|---|---|
| **L1.1** | 数据集来自**百度搜索日志**，领域偏通用 | ⚠️ 结论**不能直接外推**到医疗、法律、代码等垂直领域 |
| **L1.2** | ModelScope 版本是**采样版**（每 query 取 DPR top-1000） | ⚠️ 与论文全量实验**指标不可直接比较** |
| **L1.3** | 标注是**二元相关**（相关/不相关），非分级 | 无法评测"细粒度相关性排序" |
| **L1.4** | 可能存在**标注噪声** | 指标有天花板（无法达到 1.0） |

### 局限 2：规模局限 ⚠️

```
⭐⭐ 最关键的一条：

  本项目主实验的语料库规模是【10 万 ~ 100 万段落】
        ↓
  而真实生产系统是【千万 ~ 亿级】
        ↓
  ⚠️ 这个差异会导致：
     · 检索难度不同（库越大越难）
     · 稠密检索 vs BM25 的相对优劣可能变化
     · 索引与延迟特性完全不同
        ↓
  ⭐ 所以：结论只在"中小规模"下成立
```

> **应对**：报告中**必须明确标注语料库规模**，并对"规模效应"做讨论（如有条件，跑 100 万验证趋势）。

### 局限 3：语言局限

| 局限 | 说明 |
|---|---|
| 仅**中文** | 结论不适用于英文/多语言 |
| 分词依赖 jieba | ⚠️ **中文 BM25 的效果高度依赖分词质量**，换分词器结果可能变化 |

### 局限 4：模型局限

| 局限 | 说明 |
|---|---|
| 只用 **BGE 系列** | 未覆盖其他中文嵌入模型（如 Conan、M3E） |
| 未做**领域微调** | 结论基于通用模型 |
| 未评测**多向量检索**（ColBERT 类） | 属于前沿方向，超出本项目范围 |

## 二、⚠️ 方法论局限

### 局限 5：评测指标的固有缺陷

```
⚠️ 检索指标 ≠ 用户满意度

   nDCG 高 ≠ 用户觉得好用
        ↓
   因为：
     · 指标基于"标注相关"，而标注是【众包/规则】产生的
     · 用户真实需求可能是"快速找到答案"，而非"相关文档列表"
     · 多轮对话场景下，单轮检索指标失去意义
        ↓
   ⭐ 所以：本项目评测的是【检索质量】，不是【端到端体验】
```

### 局限 6：无法覆盖完整 RAG 链路

```
⚠️ 严格说，RAG = 检索 + 生成
        ↓
   本项目【主体是检索】
        ↓
   检索好 ≠ 生成答案好：
     · LLM 可能忽略检索到的正确上下文
     · LLM 可能基于无关上下文产生幻觉
     · 引用准确性是独立问题
        ↓
   ⭐ 端到端 QA 评测是【加分项】，不是主体
```

### 局限 7：显著性检验的局限

| 局限 | 说明 |
|---|---|
| 配对 t 检验假设**近似正态** | nDCG 分布可能偏离正态 |
| 未做**多重比较校正** | ⚠️ 试了 20 个配置取最好，显著性会被高估 |

> **应对**：明确说明"做了多少次比较"，或使用 Bonferroni 校正。

## 七、⭐ 局限说明模板（写报告时直接用）

**⭐ 实验报告必须包含以下段落（建议原文采用）：**

```markdown
## 局限说明

### 数据规模
本实验使用 XX 万段落作为语料库，而生产级检索系统通常在千万级以上。
在更大规模下，检索难度会上升，本项目的结论可能不适用。因此，
本文所有指标应理解为"在中等规模中文检索任务上的相对比较"，
而非绝对性能声明。

### 数据集领域
DuReader-retrieval 源自通用网页搜索，结论不适用于垂直领域
（如医疗、法律、代码检索）。

### 评测范围
本项目评测的是*检索质量*（基于标注相关性），不是端到端 RAG 效果。
检索指标高不保证生成答案质量，反之亦然。

### 方法覆盖
本项目未评测多向量检索（如 ColBERT）、领域微调、检索-生成联合优化
等方向，这些可能带来额外提升。

### 统计效力
提升的显著性检验基于配对 t 检验，假设分数近似正态分布。
对于提升幅度 < 1% 的结论，建议谨慎解读。

### 声明
本项目为学习性实验，未做生产级工程优化（分布式、索引压缩、
在线服务优化等），延迟数据不代表生产环境表现。
```
